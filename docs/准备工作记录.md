## 六、遇到的问题与规避

1. **apt 索引过期会报 404**：上一轮工作里遇到过 ROS 仓库返回 `404 Not Found`
   （索引里的版本比仓库现有 deb 新）。本次**先 `sudo apt update`** 再安装，避免重蹈覆辙。
   实测刷新索引 16.4 MB / 35 秒。
2. **ROS CLI 发现图可能过期**：`ros2 topic list` / `topic info` 有时看不到实际在发布的话题。
   判断节点是否真在发数据，用 `rclpy` 直接订阅最可靠；必要时
   `ros2 daemon stop && ros2 daemon start`。
3. **虚拟机是软件渲染**：`glxinfo -B` 显示
   `Vendor: VMware, Inc. (SVGA3D)`、`OpenGL 4.1 (Compatibility Profile) Mesa 25.2.8`、
   **`Accelerated: no`**（无硬件加速）。Gazebo Harmonic 要求 OpenGL 3.3+，4.1 满足，
   所以能跑；但预期帧率与流畅度有限，`dmesg` 里也出现过 `vmwgfx: mob memory overflow` 警告。
   已装 `mesa-utils` 便于随时用 `glxinfo -B` 复核。**结论：可以继续，但要把仿真窗口开小一些、
   避免全屏，并且首次启动留足加载时间。**
4. **客户机 IP 随时可能变**：虚拟机是桥接到 WLAN，IP 由路由器 DHCP 分配；
   `vm-remote/vm.ps1` 会按 MAC `00-0C-29-7A-80-87` 自动重新发现，直接用 `vm.ps1 status` 即可。
